L’essentiel – Programmation en Python

Ce qu’il faut retenir du chapitre, sur une fiche à relire ou à imprimer.

⚠️ À savoir

Cette fiche ne remplace pas le cours. Il est important de réviser le cours lui-même (séances, documents, activités et TP) : la fiche « L’essentiel » est un support complémentaire de révision.

Informatique = information + automatique. Un programme est une suite d’instructions, écrites dans un langage de programmation (ici Python), exécutées dans l’ordre par la machine.

📦 Variables et types

  • Une variable a un nom, un type et une valeur, stockée dans la mémoire vive (RAM).
  • Types : int (entier), float (décimal), str (texte), bool (vrai/faux).
  • Le signe = affecte une valeur (ce n’est pas le « = » des maths).
age = 16          # int
masse = 75.4      # float
prenom = "Michel" # str

⌨️ Entrées, sorties, opérations

  • print() affiche : flux de sortie. input() lit une saisie : flux d’entrée (texte, à convertir avec int() ou float()).
  • Opérateurs : + - * /, ** (puissance) ; + entre deux textes = concaténation.
a = int(input("Saisir un entier : "))
print("Le double vaut", 2 * a)

🔀 Conditions

if note >= 10:
    print("Admis")
elif note >= 8:
    print("Rattrapage")
else:
    print("Refusé")

Comparaisons : == (égal), != (différent), <, <=, >, >=. Le bloc est indenté et l’en-tête finit par :.

🔁 Boucles

for i in range(0, 5):   # i = 0, 1, 2, 3, 4
    print(i)

n = 1
while n < 100:          # tant que c’est vrai
    n = n * 2

for : nombre de répétitions connu. while : on répète tant que l’assertion est vraie (attention aux boucles infinies).

🧩 Fonctions et bibliothèques

def somme(nb1, nb2, nb3):
    return nb1 + nb2 + nb3

print(somme(1, 2, 3))   # affiche 6

from random import *
de = randint(1, 6)       # entier entre 1 et 6

def définit une fonction réutilisable ; return renvoie le résultat. Une bibliothèque (module) regroupe des fonctions déjà écrites.

📋 Listes

notes = [12, 15, 9]
print(notes[0])        # 12 : le 1er élément est au rang 0
notes.append(18)       # ajoute 18 à la fin
for n in notes:
    print(n)

Une liste stocke plusieurs valeurs, repérées par leur rang (indice), en commençant à 0.
