Correction – Comprendre le Web

Séance 1 · Questions 1 à 7 sur les documents 1 à 4

1 Question 1 – URL du site likes.org

http://www.likes.org/Espace-Numerique

ÉlémentValeur
Protocolehttp (protocole HTTP, non sécurisé)
Nom de domainewww.likes.org
Chemin de la ressource/Espace-Numerique

Le « / » qui suit le nom de domaine n’en fait pas partie : il commence le chemin.

2 Question 2 – URL de la vidéo YouTube

https://www.youtube.com/watch?v=TeiUyeXjzJ4

ÉlémentValeur
Protocolehttps (protocole HTTPS, sécurisé)
Nom de domainewww.youtube.com
Chemin de la ressource/watch?v=TeiUyeXjzJ4

Pour aller plus loin : dans le chemin, /watch désigne la page de lecture et ?v=TeiUyeXjzJ4 est un paramètre qui identifie la vidéo.

3 Questions 3 et 4 – Les langages du Web

  • Question 3 : le langage qui permet d’écrire le contenu d’une page web est le HTML.
  • Question 4 : le langage qui permet de définir le style graphique (couleurs, polices, mise en page) d’une page web est le CSS.

5 Question 5 – HTTP et HTTPS

Le protocole HTTPS est la version sécurisée du protocole HTTP : il chiffre (crypte) les données échangées entre le client (le navigateur) et le serveur. Avec HTTP, les données circulent « en clair » et peuvent être lues par une personne qui intercepte la communication. Le cadenas affiché dans le navigateur indique une connexion HTTPS.

6 Question 6 – Le lien hypertexte

Un lien hypertexte permet, à partir d’une page web, d’accéder à une autre page du même site ou d’un autre site, en cliquant dessus.

7 Question 7 – La page sans lien dans la barre de navigation

C’est la page « Ma page » (mapage.html). Son adresse URL est de la forme :

file:///…/Mon super site/mapage.html

Le protocole file indique que la page est ouverte depuis l’ordinateur et non depuis un serveur web.

Corrections apportées par rapport à ta version

  • Orthographe : « envoie » → « échange », « données envoyées et reçues » (accord), « à partir d’une page web d’accéder » → « permet d’accéder ».
  • Questions 1 et 2 : le « / » final a été retiré du nom de domaine et placé au début du chemin.
  • Question 2 : le paramètre ?v=… fait partie du chemin ; une précision pour aller plus loin est ajoutée.
