Étape 1 · Concevoir sur papier

1 Dessiner avant de coder

📝

Consigne : choisis un sujet, puis complète la fiche de conception sans ordinateur. Le projet comporte 2 pages au minimum reliées par un menu.

RubriqueÀ compléter
Sujet et public visé
Nom du site
Pages prévues (nom du fichier + rôle)
Éléments de chaque page (titre, texte, image, liste, lien…)
Couleurs et police choisies
Une fonctionnalité “plus” (formulaire, galerie, tableau…)

Dessine sur une feuille le plan de la page d’accueil : en-tête, menu, contenu principal, pied de page.

Étape 2 · Coder soi-même

2 Écrire le HTML puis le CSS

Voici le squelette minimal d’une page à compléter.

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Titre de la page</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <header>
    <h1>Nom du site</h1>
    <nav><a href="index.html">Accueil</a> <a href="page2.html">Page 2</a></nav>
  </header>
  <main>
    <!-- ton contenu ici -->
  </main>
  <footer>© ton nom</footer>
</body>
</html>
  1. Crée d’abord tout le contenu en HTML sans te soucier de l’apparence.
  2. Vérifie que les liens entre les pages fonctionnent.
  3. Ajoute ensuite le fichier style.css : couleurs, polices, marges.
  4. Teste ton site sur la largeur d’un téléphone (réduis la fenêtre).
Valider son code

Utilise le validateur W3C (validator.w3.org) pour détecter des erreurs d’HTML, et lis chaque message : c’est un excellent moyen de progresser.

Étape 3 · Utiliser l’IA avec parcimonie

3 Le budget de 4 prompts

🎟️

Consigne : tu as droit à 4 prompts pour tout le projet. Chacun doit demander une seule chose précise, en moins de 5 lignes, et tu dois comprendre et tester la réponse avant de l’utiliser.

Règles pour économiser tes prompts (et des tokens)

  • Chercher d’abord seul(e) : cours, documentation MDN, essai-erreur.
  • Décomposer : demander une seule propriété ou un seul bloc, pas tout le site.
  • Donner le contexte utile : coller seulement les quelques lignes concernées, pas toute la page.
  • Préciser le format : « donne seulement le CSS, avec un commentaire par ligne ».
  • Ne pas demander « refais tout » à chaque ajustement.
