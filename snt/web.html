☁️ Le Web

URL, protocoles HTTP et HTTPS, liens hypertextes, moteurs de recherche, cookies, HTML et CSS, droit d’auteur.

  1. 1 Comprendre le Web Repères historiques, langages du Web, URL, protocoles HTTP et HTTPS, liens hypertextes, client-serveur. ActivitéQuestions
  2. 2 Naviguer sur le web Moteurs de recherche, cookies, hameçonnage et navigation privée. Activité
  3. 3 À la découverte du HTML et du CSS Construire sa page web : balises, liens, images, vidéo, puis mise en forme avec le CSS. TPFichiers à télécharger
  4. 4 Publier dans les règles Droit d’auteur, droit à l’image, licences Creative Commons et droit à l’oubli. ActivitéCours
