Activité 2 · Construire ton tuteur

2 Un agent qui guide, mais ne donne pas la réponse

🛠️

Consigne : tu vas écrire le pré-prompt d’un agent « professeur tuteur » : il doit t’aider à résoudre un exercice sans jamais donner la réponse finale.

Utilise cette trame pour rédiger ton pré-prompt (une à deux phrases par rubrique) :

RÔLE : Tu es un tuteur de [matière] pour un élève de seconde.
OBJECTIF : L’aider à comprendre et à trouver la solution par lui-même.
RÈGLES : Ne donne jamais la réponse finale ni la solution complète.
         Pose une seule question à la fois.
         Pars de ce que l’élève sait déjà.
MÉTHODE : 1) Demande à l’élève de reformuler l’énoncé.
          2) Donne un indice, puis un second si besoin.
          3) Fais vérifier sa réponse par l’élève, explique ses erreurs.
SI L’ÉLÈVE INSISTE : Refuse poliment et propose un indice plus précis.
FORMAT : Réponses courtes (3 phrases maximum), ton bienveillant, tutoiement.

Adapte la trame à ta façon : tu peux changer le ton, le niveau d’indices ou la matière.

Cours

📘 Cours : Des chatbots aux agents

1. Définition

Un agent IA est un système construit autour d’un modèle de langage qui reçoit un objectif, décide des actions à accomplir, utilise des outils et s’adapte aux résultats obtenus, avec une autonomie variable.

  • Le chatbot répond à une question.
  • L’agent poursuit un but : il planifie, agit, observe, corrige.
  1. Percevoir : lire la demande, les fichiers, le résultat d’un outil.
  2. Décider : planifier la prochaine étape.
  3. Agir : appeler un outil (recherche, code, agenda, messagerie…).
  4. Observer le résultat et recommencer jusqu’à l’atteinte du but.

2. Les ingrédients d’un agent

Le modèle

Le LLM qui « raisonne » et formule les décisions.

Les instructions

Le pré-prompt : rôle, règles, méthode, limites.

Les outils

Recherche web, calculatrice, base de données, fichiers, messagerie…

3. Risques et bonnes pratiques

  • Erreurs en cascade : une erreur à une étape se répercute sur les suivantes.
  • Injection de prompt : un texte malveillant (message, page web) tente de détourner les instructions de l’agent ; c’est ce que tu as testé en essayant de contourner ton tuteur.
  • Droits excessifs : un agent ne doit disposer que des accès strictement nécessaires.
  • Humain dans la boucle : les actions irréversibles (paiement, envoi de message, suppression) doivent être validées par une personne.
Vocabulaire · Injection de prompt

Attaque qui consiste à glisser dans une entrée (message, page, document) des instructions cachées pour détourner le comportement d’un modèle.

À retenir

Un bon agent n’est pas seulement « intelligent » : il est cadré (instructions claires), limité (peu de droits) et contrôlé (validation humaine).
