Le mot inforatique peut se décomposer en deux mots.

Il est composé du mot information et du mot automatique.

Brièvement, l’informatique c’est de le traitement de l’information traitée de manière automatique.


Les deux machines les plus populaires qui traitent automatiquement l’information sont l’ordinateur et le téléphone portable.

Afin que la machine puisse traitée l’information, il est important qu’elle puisse communiquer avec un utilisateur pour répondre à ses besoins ou encore avec une autre machine afin de maintenir des services comme le réseau internet.


Pour mettre en place cette communication entre l’homme et la machine ou de la machine avec la machine. La machine qui traite l’information doit connaître certaines règles afin de pouvoir traitée correctement les informations qu’elle reçoit.


Certains historien attribue le début de l’informatique dû à l’invention de la pascaline, machine à calculer créer en 1652 par Blaise Pascal. A l’aide d’un système de rouages, cette machine permet de calculer automatiquement le résultat d’une opération, l’utilisateur saisit les nombres qu’il souhaite voient opérée et la machine lui renvoie le résultat.



Pendant la seconde guerre mondiale, la machine de Turing ayant pour but de décrypter les messages émis par les Nazis, comportant des ordres militaires, est une machine à rouage également. Cependant elle s’appuie sur une énergie que Blaise Pascal ne disposer pas. L’électricité.



Avec la création du transistor en 1948.

et le développement de l’électronique, sont les inventions à l’origine de notre informatique moderne.


Les règles ou plutôt les instructions connues par la machine pour permettre leurs bonne exécutions sont actuellement écrites par un développeur informatique qui détaille ce que la machine doit faire suivant les informations qu’elle récupère. C’est part ce travail que l’on conçoit les systèmes d’exploitations, applications, jeux vidéos, logiciels. Pour que le développeur puisse transmettre de ses instructions à la machine, ils utilisent tous les deux un langage qu’ils comprennent. Ce langage est appelé langage de programmation. Il existe un nombre considérable de langage de programmation. Dans ce cours de science numérique, nous allons travaillé avec le langage de programmation python.
