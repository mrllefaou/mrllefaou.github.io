L’essentiel – Le Web

Ce qu’il faut retenir du chapitre, sur une fiche à relire ou à imprimer.

⚠️ À savoir

Cette fiche ne remplace pas le cours. Il est important de réviser le cours lui-même (séances, documents, activités et TP) : la fiche « L’essentiel » est un support complémentaire de révision.

Le Web est un ensemble de pages reliées par des liens hypertextes. C’est un service qui utilise le réseau Internet : un navigateur demande les pages à des serveurs grâce au protocole HTTP(S).

🕰️ Repères

  1. 1965Ted Nelson invente le concept d’hypertexte.
  2. 1989Tim Berners-Lee invente le Web au CERN.
  3. 1993Le Web passe dans le domaine public ; premier navigateur grand public, Mosaic.
  4. 1995JavaScript et PHP : des sites interactifs et dynamiques.
  5. 2001Les pages sont standardisées grâce au DOM.
  6. 2010Des technologies pour les applications sur mobiles.

Le S de HTTPS : les échanges sont chiffrés et l’identité du site est vérifiée par un certificat. Cela ne garantit pas que le contenu est fiable.

🔁 Que se passe-t-il quand j’ouvre une page ?

💻 Clientle navigateur
① requête HTTP(S) : « envoie-moi cette page » →← ② réponse : fichiers HTML, CSS, images
🗄️ Serveurl’ordinateur qui héberge le site

③ Le navigateur lit le HTML (le contenu et sa structure) et le CSS (la mise en forme) pour afficher la page.

📖 Vocabulaire

Internet
Le réseau mondial qui relie les ordinateurs entre eux.
Web
Un service d’Internet : des pages reliées par des liens.
Lien hypertexte
Élément cliquable qui mène vers une autre ressource.
HTML / CSS
Langages des pages : le contenu (HTML) et le style (CSS), normalisés par le W3C.
Moteur de recherche
Des robots parcourent et indexent les pages ; un algorithme les classe (ex. PageRank).
Cookie
Petit fichier déposé par un site dans le navigateur. Un cookie tiers vient d’un autre site (souvent publicitaire) et suit la navigation.
Hameçonnage
Faux message ou faux site qui imite un vrai pour voler des identifiants.
Navigation privée
N’enregistre ni historique ni cookies sur l’appareil, mais ne rend pas anonyme sur le réseau.

⚖️ Publier dans les règles

  • On est responsable de ce que l’on publie, même sous pseudonyme.
  • Droit d’auteur : le droit moral est perpétuel ; les droits patrimoniaux durent jusqu’à 70 ans après la mort de l’auteur. Citer l’auteur ne suffit pas : il faut son autorisation.
  • Droit à l’image : il faut l’accord d’une personne reconnaissable pour publier sa photo.
  • Licences Creative Commons : l’auteur indique ce qu’on a le droit de faire de son œuvre (BY, NC, ND, SA).
  • Droit à l’oubli : on peut demander le déréférencement d’informations personnelles.

✅ Je sais…

  • régler les cookies et la confidentialité de mon navigateur ;
  • repérer une tentative d’hameçonnage ;
  • publier en respectant le droit d’auteur et le droit à l’image.
