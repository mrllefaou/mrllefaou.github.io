1 QCM 1 – Définitions et règles (13 questions)

  1. Une équation est :

    Bonne réponse : une égalité entre deux expressions comportant des lettres

    Par exemple 2x + 1 = 3.

    📖 Cours, chapitre 7 : Définition 1

  2. Résoudre une équation d’inconnue x, c’est :

    Bonne réponse : trouver toutes les valeurs de x qui vérifient l’égalité

    Chacune de ces valeurs est une solution.

    📖 Cours, chapitre 7 : Définition 2

  3. 2 est-il solution de 3x − 1 = 5 ?

    Bonne réponse : Oui, car 3 × 2 − 1 = 5

    On remplace x par 2 : l’égalité est vraie.

    📖 Cours, chapitre 7 : Définition 2 (Exemple 2)

  4. Dans une équation, on peut toujours :

    Bonne réponse : ajouter le même nombre aux deux membres

    Si a = b, alors a + c = b + c.

    📖 Cours, chapitre 7 : Propriété 1

  5. Dans une équation, on peut diviser les deux membres par un nombre c à condition que :

    Bonne réponse : c ≠ 0

    Si a = b, alors a/c = b/c avec c ≠ 0.

    📖 Cours, chapitre 7 : Propriété 4

  6. A × B = 0 signifie :

    Bonne réponse : A = 0 ou B = 0

    Un produit est nul si l’un de ses facteurs est nul.

    📖 Cours, chapitre 7 : Propriété 5

  7. Une inégalité est une expression contenant l’un des symboles :

    Bonne réponse : <, ≤, > ou ≥

    Par exemple x > 17.

    📖 Cours, chapitre 7 : Définition 3

  8. Une inéquation est :

    Bonne réponse : une inégalité contenant une ou plusieurs inconnues

    Par exemple 3x + 10 < −2x + 7.

    📖 Cours, chapitre 7 : Définition 4

  9. Si on multiplie les deux membres d’une inégalité par un nombre négatif :

    Bonne réponse : on change le sens de l’inégalité

    Si a < b et c ≤ 0, alors a × c > b × c.

    📖 Cours, chapitre 7 : Propriété 9

  10. Si on ajoute le même nombre aux deux membres d’une inégalité :

    Bonne réponse : le sens ne change pas

    Si a < b, alors a + c < b + c.

    📖 Cours, chapitre 7 : Propriété 6

  11. Si on divise les deux membres d’une inégalité par un nombre positif :

    Bonne réponse : le sens ne change pas

    Si a < b et c > 0, alors a/c < b/c.

    📖 Cours, chapitre 7 : Propriété 10

  12. x > 17 désigne :

    Bonne réponse : les nombres strictement supérieurs à 17

    Le symbole > est strict : 17 n’est pas compris.

    📖 Cours, chapitre 7 : Définition 3 (Exemple 10)

  13. Laquelle de ces écritures est une équation ?

    Bonne réponse : 3x + 1 = 7x + 3

    C’est une égalité avec une inconnue. « 2 + 3 = 5 » n’a pas de lettre ; « 3x + 1 < 7 » est une inéquation.

    📖 Cours, chapitre 7 : Définitions 1 et 4

2 QCM 2 – Résoudre (13 questions)

  1. Résoudre x − 5 = 3 :

    Bonne réponse : x = 8

    On ajoute 5 des deux côtés : x = 3 + 5 = 8.

    📖 Cours, chapitre 7 : Propriété 1

  2. Résoudre 2x + 1 = 2 :

    Bonne réponse : x = 12

    2x = 2 − 1 = 1, puis x = 1/2.

    📖 Cours, chapitre 7 : Propriétés 2 et 4

  3. Résoudre −x − 7 = −2 :

    Bonne réponse : x = −5

    −x = −2 + 7 = 5, donc x = −5.

    📖 Cours, chapitre 7 : Propriétés 1 et 3

  4. Résoudre 2x + 1 = x − 3 :

    Bonne réponse : x = −4

    2x − x = −3 − 1, donc x = −4.

    📖 Cours, chapitre 7 : Propriétés 1 et 2

  5. Résoudre 5x + 2 = 27 :

    Bonne réponse : x = 5

    5x = 25, donc x = 5.

    📖 Cours, chapitre 7 : Propriétés 2 et 4

  6. Résoudre (x − 5)(2x + 2) = 0 :

    Bonne réponse : x = 5 ou x = −1

    x − 5 = 0 donne x = 5 ; 2x + 2 = 0 donne x = −1.

    📖 Cours, chapitre 7 : Propriété 5

  7. Résoudre x(5x − 1) = 0 :

    Bonne réponse : x = 0 ou x = 15

    x = 0 ou 5x − 1 = 0, c’est-à-dire x = 1/5.

    📖 Cours, chapitre 7 : Propriété 5

  8. Résoudre (2x + 1)(5x − 2) = 0 :

    Bonne réponse : x = −12 ou x = 25

    2x + 1 = 0 donne x = −1/2 ; 5x − 2 = 0 donne x = 2/5.

    📖 Cours, chapitre 7 : Propriété 5 (Exemple 8)

  9. Résoudre x − 5 < 3 :

    Bonne réponse : x < 8

    On ajoute 5 : x < 8.

    📖 Cours, chapitre 7 : Propriété 6

  10. Résoudre −2x + 1 < 2 :

    Bonne réponse : x > −12

    −2x < 1, puis on divise par −2 (négatif) : on change le sens, x > −1/2.

    📖 Cours, chapitre 7 : Propriétés 7 et 11

  11. Résoudre −x − 7 > −2 :

    Bonne réponse : x < −5

    −x > 5 ; en multipliant par −1, on change le sens : x < −5.

    📖 Cours, chapitre 7 : Propriétés 6 et 9

  12. Résoudre 2x + 2 < 3x − 3 :

    Bonne réponse : x > 5

    2 + 3 < 3x − 2x, soit 5 < x, donc x > 5.

    📖 Cours, chapitre 7 : Propriétés 6 et 7

  13. Résoudre 3x + 10 < −2x + 7 :

    Bonne réponse : x < −35

    3x + 2x < 7 − 10, soit 5x < −3, puis x < −3/5 (on divise par 5 > 0).

    📖 Cours, chapitre 7 : Propriétés 6, 7 et 10

3 QCM 3 – Mettre en équation (13 questions)

  1. Trouver le nombre dont le quintuple augmenté de 7 est égal à 3 :

    Bonne réponse : −0,8

    5x + 7 = 3, donc 5x = −4 et x = −4/5 = −0,8.

    📖 Cours, chapitre 7 : Partie 4 (Exemple 9)

  2. La somme de trois entiers consécutifs est 48. Ces entiers sont :

    Bonne réponse : 15, 16 et 17

    x + (x + 1) + (x + 2) = 48, donc 3x + 3 = 48, 3x = 45, x = 15.

    📖 Cours, chapitre 7 : Partie 4 : modéliser un problème

  3. Un rectangle a un périmètre de 30 cm et sa longueur est le double de sa largeur ℓ. Alors ℓ =

    Bonne réponse : 5 cm

    2(2ℓ + ℓ) = 30, donc 6ℓ = 30 et ℓ = 5 cm.

    📖 Cours, chapitre 7 : Partie 4

  4. Un père a 30 ans de plus que son fils ; la somme de leurs âges est 50 ans. Le fils a :

    Bonne réponse : 10 ans

    x + (x + 30) = 50, donc 2x = 20 et x = 10.

    📖 Cours, chapitre 7 : Partie 4

  5. Tarif A : 5 € la place. Tarif B : abonnement de 20 € puis 3 € la place. Les tarifs sont égaux pour :

    Bonne réponse : 10 places

    5x = 20 + 3x, donc 2x = 20 et x = 10.

    📖 Cours, chapitre 7 : Partie 4 et Propriétés 2 et 4

  6. Mêmes tarifs. Le tarif B est strictement moins cher que le tarif A pour :

    Bonne réponse : 11 places ou plus

    20 + 3x < 5x donne 20 < 2x, soit x > 10.

    📖 Cours, chapitre 7 : Propriétés 7 et 10

  7. Résoudre x² = 9 :

    Bonne réponse : x = 3 ou x = −3

    x² − 9 = 0, soit (x − 3)(x + 3) = 0 : x = 3 ou x = −3.

    📖 Cours, chapitre 7 : Propriété 5 (et 3e identité remarquable)

  8. Résoudre x² = 2x :

    Bonne réponse : x = 0 ou x = 2

    x² − 2x = 0, soit x(x − 2) = 0. Ne pas diviser par x : on perdrait la solution 0 !

    📖 Cours, chapitre 7 : Propriété 5

  9. Programme : multiplier par 3 puis ajouter 4. On obtient 19. Le nombre de départ est :

    Bonne réponse : 5

    3x + 4 = 19, donc 3x = 15 et x = 5.

    📖 Cours, chapitre 7 : Partie 4

  10. −1 est-il solution de x² + 2x + 1 = 0 ?

    Bonne réponse : Oui

    (−1)² + 2 × (−1) + 1 = 1 − 2 + 1 = 0 : l’égalité est vérifiée.

    📖 Cours, chapitre 7 : Définition 2

  11. Les nombres dont le double diminué de 3 est strictement supérieur à 7 sont :

    Bonne réponse : les nombres strictement supérieurs à 5

    2x − 3 > 7, donc 2x > 10 et x > 5.

    📖 Cours, chapitre 7 : Propriétés 6 et 10

  12. Résoudre 4 − 2x ≥ 0 :

    Bonne réponse : x ≤ 2

    −2x ≥ −4 ; on divise par −2 (négatif) : on change le sens, x ≤ 2.

    📖 Cours, chapitre 7 : Propriétés 7 et 11

  13. 3 cahiers et 1 stylo à 1,50 € coûtent 7,50 €. Un cahier coûte :

    Bonne réponse : 2 €

    3x + 1,5 = 7,5, donc 3x = 6 et x = 2.

    📖 Cours, chapitre 7 : Partie 4
